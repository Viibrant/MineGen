# Notebooks

This directory contains the original research notebooks used during development. These have been preserved for reference but the code has been integrated into the main codebase.

## Contents

- `exploratory.ipynb` - Initial data exploration and analysis
- `patch.ipynb` - Hierarchical transformer model development  
- `temp.py` - Experimental transformer implementations
- `train_embeddings.ipynb` - Autoencoder and embedding experiments
- `vae.ipynb` - VAE model development and training

## Note

The models and functionality from these notebooks have been refactored and integrated into the main `src/` codebase with proper type hints, error handling, and modern Python practices.
